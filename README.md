# Software-Quality-Metrics-
Good software isn't just code that works.
It's the code that remains understandable, changeable, and reliable.

Here are a few parameters of a good software: 

- Correctness:
  Does it safely do the requirements?
- Modifiability:
  Adaptability to different environments.
  Change in requirements.
  Bug fixes
- Reusability
- Efficiency
  Best possible use of the available resources
